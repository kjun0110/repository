## 개념

- **처리 장소 vs 담당부서** — 시민이 몸을 옮기는 곳(`visit_place`)과 업무를 책임지는 조직(`HANDLED_BY`). 복지 민원은 둘이 다르다
- **역상속** — 자식 조직 전원이 같은 건물일 때 부모에게 주소를 올리는 것. 층은 버리고 건물 주소까지만
- **창(窓) 규칙** — 규칙을 값 자체가 아니라 값 주변 문자 범위에 거는 것. 무관한 이웃까지 걸려 정답을 지운다

## 2. 장소 — 담당부서와 처리 장소는 다른 개념

##### 문제 — 담당부서 주소로 안내하면 헛걸음
그래프에는 담당부서만 있었음. 페이지 하단 고정 항목이라 진작 수집돼 있었기 때문이다. 담당조직 주소가 시청(효원로 241)인데 본문은 "동 행정복지센터로 가라"고 하는 민원이 81건이다. 장애연금·기초연금·아동수당·출산지원금 등 복지 민원 전반.

##### 계획 착오 — 라벨이 이 축의 핵심이 아님
`[위치]:` 라벨로 세어 15건으로 잡고 시작했다. 실제 분포는 다름.

```
라벨 정규식        133개 값 → 중복·URL·모호형 제거 → 19건, 그중 9건이 오탐
기관어 + 행위 문맥   102건 (동 행정복지센터·보건소·구청)
합                166건 / 302값
```

계획서에는 `주소지 동 행정복지센터`를 "모호하니 배제"로 적어 뒀다. 정확히 반대다. 시민에게 "본인 동 행정복지센터로 가세요"는 완결된 안내이고, 동까지 말하면 `region` 축이 실제 주소를 짚는다.

##### 정규화 — 기각. 수식어가 표기가 아니라 기준점
```
주소지 구청                아동수당       → 사는 곳 기준
주택소재지 관할구청           취득세 감면      → 주택 위치 기준
영업소가 소재하는 관할 구청     모범음식점      → 가게 위치 기준
사고가 발생한 해당 구청        도로관리       → 사고 지점 기준
해당 구청                 주차위반 이의신청   → 위반 장소 기준
```

전부 `주소지 관할 구청`으로 묶으면 영통구 주민이 팔달구에서 주차위반을 하고 영통구청으로 간다. 행정복지센터도 같다 — `주소지 46 · 관할 15 · 거주지 3`은 같은 뜻이나 `전국 3`(등초본·주민등록증)은 다른 뜻이고, `주소지`로 바꾸면 되는 걸 안 된다고 좁힌다.

> **정정.** 0826에서 이미 "원문 표현마다 뜻이 다르니 보존한다"를 배웠는데, 이 축에서는 "닫힌 집합이라 안전하다"고 반대로 판단했다. 데이터가 아니라 직관으로 정했기 때문이다.

##### 구현 ① `OrgUnit.address` — 기준 건물 주소를 데이터에서 도출
`nodes/01_org_units.py:82`가 `dept_meta.location`을 진작 적재하고 있었다. 새 컬럼이 아니라 쓸 수 없는 값을 쓸 수 있게 만드는 작업이다.

```
186건 보유
  106건  도로명 있음 (스크랩 중복 혼입)
   79건  건물·층만 — "시청 별관3층", "팔달구청 2층"
    1건  건물명만 — "팔달구보건소"
```

하드코딩하지 않음. 같은 건물이 어떤 줄에는 도로명과 같이, 어떤 줄에는 건물명만 적혀 있어 서로를 메운다. `"…효원로 241(수원시청) 별관 6층"`에서 `별관 · 수원시청 = 효원로 241`을 얻고, `"시청 별관3층"`에 `효원로 241`을 붙인다. 건물 15개(시청·구청 4·보건소 4·사업소 4·의회). 사전이 비면 실패로 중단하게 했다 — 원천 형식이 바뀌면 조용히 통과하면 안 된다.

두 가지 교정이 필요했다. 다중 장소 값은 사전 도출에서 뺀다(`"시민청팀…: 시청 본관1층 / 여권팀 : 팔달구 월드컵로 336"`을 쓰면 '시청'과 '본관'이 여권팀 주소로 묶인다). 그리고 표기 차이로 1:1 동점이 나므로(`경기도 수원시 장안구 송원로 101 (조원동)` vs `수원시 장안구 송원로 101`) 도(道)와 괄호를 뗀 키로 묶고 대표값은 가장 자세한 표기를 남긴다.

##### 구현 ② 상속 — 양방향
```
자기 값    185
상속       683   PART_OF 상위 4단계
역상속      22   자식 전원이 같은 건물일 때만, 층은 버리고 건물 주소까지
합         890 / 939
```

역상속은 계획에 없었음. 화성사업소·수원시립미술관·상수도사업소·보건소 4곳이 자기 주소가 비고 그 밑의 과가 갖고 있어 "화성사업소 어디 있어요"가 통째로 안 되는 상태였다. 자식이 갈리면 올리지 않는다 — 경제정책국은 기업지원과(본관4층)와 지역경제과(별관5층)로 갈려 비워 뒀다.

##### 결과 — 도로명 없는 주소 80건 → 0건
실패 1건(`의회신청사 3층 의회사무국`)은 그 건물의 도로명이 데이터 어디에도 없어 채우지 않고 로그에 남겼다.

## 3. 서류 발급처 — 롱테일이라 수작업 매핑 기각

##### 문제 — 지금 날조 중
```
Q  기초연금 신청에 필요한 통장사본 어디서 발급받아요
A  "주소지관할 동 행정복지센터에서 발급받을 수 있습니다"   ← 은행이다
```

빈 칸을 컨텍스트의 다른 주소로 메운다. 담당부서 빈칸을 분야값으로 채우던 것과 같은 기제다([[0821_KG - Layer 2 전 분야 확장 및 검색·데이터 구조 정리]]). 이 사실이 우선순위를 뒤집었다 — 관련 기관은 덜 말할 뿐이고 서류 발급처는 실제로 날조하고 있었다.

##### 안 ① 상위 20종 수작업 매핑 — 기각
```
상위  10종  190 / 890 REQUIRES  (21%)
상위  20종  238                 (27%)
상위 100종  381                 (43%)
543종이 딱 한 번만 쓰이는 롱테일
```

##### 택한 안 — 접미사 규칙 12개
발급처가 이름의 접미사로 거의 결정된다. `387 / 609종 = 661 / 890 REQUIRES (74%)`.

##### 순서 — 양식어가 주제어보다 먼저 물어야 함
```
임신·출산 진료비 지원(변경)신청서   → 의료기관   ('진료'가 먼저 물었을 때)
두드림통장 지원사업 신청서        → 은행      ('통장'이 먼저)
잔액 전환 신청서 / 금융거래정보제공동의서 → 은행
```

이름이 `~신청서/신고서/동의서`로 끝나면 무엇에 관한 양식이든 접수처 것이다. 이 판정을 규칙 맨 앞으로 올려 해결했다.

##### 오분류 — 확인서는 양식이 아님
`확인서$`를 양식 규칙에 넣었으나 확인서는 남이 발급해 주는 서류다.

```
임신확인서 · 입·퇴원확인서      → 병원
육아휴직 확인서 · 경력증명서     → 사업주
재학증명서 · 졸업증명서        → 학교
그 밖의 확인서              → 발급 주체가 제각각이라 미배정
```

##### 결과 — "발급처 없음"이 45%
```
접수처에 비치 — 미리 떼 올 필요 없음    256 REQUIRES
본인이 이미 갖고 있는 것              144
                                합 400 = 45%
```

`신분증은 어디서 떼나요`는 물을 필요가 없는 질문이고 `소득·재산 신고서`는 접수처에 비치돼 있다. "따로 뗄 필요 없다"가 시민에게 완결된 답이고, 날조가 나던 자리가 정확히 여기다.

##### 미배정 229건 — 가드
```
  - 사실(이)혼관계확인서 (발급처가 원문에 없음)
  ※ '발급처가 원문에 없음'인 서류는 어디서 떼는지 우리가 모른다 — 추측하지 말고,
    위에 적힌 처리 장소나 담당부서 주소를 그 서류의 발급처인 것처럼 답하지 말 것.
```

담당부서 빈칸을 `"원문에 표기 없음(추측하지 말 것)"`으로 막은 것과 같은 수법이다. 채우는 것보다 "모른다고 말하게 만드는 것"이 어렵고, 검증에서도 그쪽이 진짜 시험이었다.

## 4. 관련 기관 — 기존 축과 겹쳐 76건이 26건

##### 문제 — 갈 수 있는 곳 하나를 안 알려줌
수원시 창구와 병행하는 국민연금공단 지사·고용센터·국민건강보험공단이 답변에 없다.

##### `external_org` 재사용 — 기각
`external_org`는 "수원시 소관이 아님"이라는 배타적 신호다(6건). 기초연금에 붙이면 "수원시는 상관없다"가 되어 더 틀린다.

##### 순증분 — 세 번 깎음
```
1차   외부기관을 신청 맥락으로 언급한 민원                   79건
2차   복지로 21중 14 · 정부24 18중 15가 이미 Channel 축에 있음   → 오프라인 ~40건
3차   교육청 16건이 전부 오탐                            → 24건
최종  규칙 배제 후                                     26건 / 34값
```

Channel 축과의 겹침을 안 쟀으면 40%를 중복 구현할 뻔했다. 실제 답변에도 `"인터넷 접수는 복지로를 통해"`가 이미 나오고 있었다.

##### 흡수 규칙 — 과교정 1회
부분문자열 흡수를 켜면 `경찰서`가 `장안경찰서`에 먹혀 나머지 3개 구가 사라지고, 끄면 `국민연금공단 지사 / 국민연금공단`이 두 줄로 나온다. 차이가 수식어일 때만 흡수하도록 갈랐다.

```
국민연금공단 / 국민연금공단 지사      → 같은 곳, 긴 쪽만
가까운 고용센터 / 고용센터            → 같은 곳, 긴 쪽만
경찰서 민원실 / 장안경찰서 민원실        → 다른 곳, 둘 다 남긴다
```

운전면허 반납 답변에 4개 구 경찰서가 다 나오는 게 그 결과다.

## 5. 기한 재현율 — 천장을 재고 멈춤

##### 문제 — 어디서 새는지 불명
```
후보 관문    기한 표현이 있는데 LLM에 안 간 민원   0건    안 샘
LLM 빈 결과  68건, 이미 1:1 단독 재질의까지 거침    더 물어도 같음
규칙 배제    121개                            여기만 손댈 수 있음
```

##### 원인 — `is_time_value` 58개 안에 지방세 납기가 통째로 있음
```
자동차세  "정기분 : 6.16 ~ 6.30(1기분), 12.16 ~ 12.31(2기분)"   → DROP
```

`_HAS_VALUE`가 `2026. 6. 16.`처럼 연도 4자리를 요구해 연을 생략한 월.일을 날짜로 못 읽는다. "자동차세 언제 내"는 가장 흔한 질문인데 답이 없던 상태다.

##### 구현 — 규칙 3개 수정
```
연도 없는 월.일 범위    범위(~)나 '까지/부터'가 붙을 때만 — 버전번호·금액과 구별
시각이 붙은 마감       "납기말일23:30까지" — 말일·납기·기한이 같이 있으면 운영시간이 아님
숫자 없는 상대 기한     "예약 전일까지만", "신고기간 만료일까지"
```

##### 결과 — 101 → 103건 / 218 → 228줄, 사라진 줄 0
순증분.

##### 멈춘 이유 — 남은 119개는 기한이 아님
```
"취득당시가액 12억원 이하 주택을 유상거래로 취득"   자격 요건
"ARS 이용시간 => 07:00 ~ 23:30"                운영시간
"65세 이상 월 10만원 지급"                       금액
"옥외광고물 3년 이내"                            표시기간
"사진 규격: 6개월 이내 촬영"                       사진 유효기간
```

전량 확인했고 더 열면 정밀도가 무너진다.

> **정정.** 0826의 "재현율 49%"를 정정한다. 그 분모는 느슨한 정규식이 잡은 모든 기한 표현이었는데 대부분이 애초에 기한이 아니었다. 다시 재면 본문에 기한 표현이 있는데 비어 있는 76건 중 진짜 놓친 것은 20건 안팎이고 그중 10건을 회수했다. "49% → 98%" 같은 개선은 애초에 가능한 종류가 아니다.

## 6. 규칙 오탐 — 전부 경계를 안 잡아서

##### 부분문자열 오매칭 3종
0826에 "낱말 목록 규칙은 예외 없이 오탐을 낸다"고 적었는데 하루에 세 번 더 걸렸다.

```
아[동의] 난민인정증명서        → '동의'가 걸려 양식으로 분류
권선구 + 구청 = 권선구구청      → 구 이름 끝 글자가 겹침
문의 [교육청]년청소년과        → 수원시 부서에서 '교육청' 16건 오탐
```

셋 다 값 자체는 정상이고 낱말이 다른 낱말 안에 들어 있었을 뿐이다. `동의`는 양식어 바로 뒤에 '서'를 요구하고, `구청`은 `gu[:-1]`로 끝 글자를 겹치지 않게 하고, `교육청`은 `교육청(?!년)`으로 막았다.

##### 창(窓) 규칙 — 정답 3건 삭제
부정문 배제를 앞뒤 26자 안에서 찾게 했더니 장소와 무관한 부정까지 걸렸다.

```
"발급 (대리발급 불가) 발급기관 : … 읍,면,동 행정복지센터"
         ^^^^ 불가한 건 대리발급이지 그 장소가 아니다
"3회 연체 6개월간 대여 불가 … 각 동 행정복지센터"
"근로가 불가하다고 판단되는 자 … 주소지 동 행정복지센터 근무조건"
```

부정은 기관명 뒤에서만 본다. 고치자 재현율 95% → 98%.

> **정정.** 0826의 "같은 실수를 세 번 했다 — 검증을 경로에 걸었다"와 같은 부류의 네 번째다. 그때는 경로에 걸었고 이번엔 창에 걸었다. 둘 다 검증을 값에 붙이지 않아 생긴다.

##### 대조 도구 — 버킷당 상위 26종만 출력
609종 배정을 버킷별로 덤프해 비교했으나 도구가 자르고 있었다. `None → 접수처 비치` 같은 유령 변경이 섞이고 정작 잡아야 할 오탐은 안 보였다. 전량 출력으로 고치고 나서야 `아동의 난민인정증명서`가 드러났다. 전량 대조를 한다면서 도구가 자르면 안 한 것과 같다.

## 7. 라벨 분리 — 주소가 둘이면 우선순위를 명시해야 함

##### 문제 — 주소가 둘이면 LLM이 가까운 걸 집음
`fee_text`/`benefit_text`를 갈라야 했던 것과 같다. 첫 검증에서 장애연금 답변에 담당부서 주소가 처리 장소와 나란히 나왔다. 답은 맞았지만(동 행정복지센터를 먼저 말함) 두 주소가 같은 무게로 보였다.

##### 구현 — 우선순위 4단
```
처리 장소 있음 (166건)
  이 민원의 처리 장소(담당부서 소재지가 아니라 여기로 간다): 주소지 동 행정복지센터
  담당부서(장애인복지과) 사무실 위치(방문처 아님 — 위의 처리 장소로 간다): 효원로 241 별관1층

자기 주소 (185건)
  위치: 경기도 수원시 팔달구 효원로 241 (인계동) 시청 본관3층

상속 주소 (705건)
  위치(상위 부서 기준): … — 층·호실을 이 조직의 것으로 단정하지 말 것

구·동마다 있는 조직
  주소 줄 자체를 내지 않는다
```

마지막이 중요하다. `peer_count > 1`인 조직에는 이미 "특정 지점을 지정하지 말라"는 가드가 있어(행정지원과 5개·건축과 5개) 주소를 찍으면 정면으로 뒤집는다.

`visit_place`가 있을 때 담당부서 줄을 "방문처 아님"으로 못박아 해결했다.

## 재사용 가능한 판단

- **정규화는 표기 차이에만 한다. 수식어가 기준점을 정하면 원문을 보존한다.** `주소지/해당/전국`은 표기가 아니라 뜻이다.
- **낱말 목록보다 경계를 먼저 정한다.** 하루에 부분문자열 오매칭을 세 번 냈다.
- **규칙은 값에 건다. 창(窓)에 걸면 무관한 이웃까지 지운다.**
- **"모른다"를 명시적으로 답하게 만드는 것이 채우는 것보다 어렵고 더 중요하다.** 빈칸을 비워 두면 LLM이 근처 값으로 메운다 — 이번 라운드에서만 두 번 확인했다.
- **기존 축과의 겹침을 먼저 잰다.** 관련 기관은 안 쟀으면 40%를 중복 구현할 뻔했다.
- **전량 대조 도구가 자르고 있지 않은지 확인한다.** 잘린 비교는 안 한 것과 같다.
- **파생값은 원문을 남기고 따로 저장한다.** `location`(원문 186)을 두고 `address`(파생 890)를 새로 만들었다. 상속값 여부가 `location IS NULL`로 판정돼 플래그 컬럼이 필요 없어졌다.
- **커버리지를 세기 전에 분모가 정당한지 본다.** "재현율 49%"는 분모가 잘못돼 나온 숫자였다.

## 한계

- 재현율을 안 쟀음. 장소·기관은 정밀도만 전량 육안 확인했고 `_ORG` 목록에 없는 기관은 분모에 안 잡힘
- 기계 보증 없음. 기한 축은 `verbatim` 대조로 원문 문자열을 보장했으나, 장소·기관의 기관어 경로는 수식어+기관명 조합이라 그 보증이 없음
- 복합 항목 오배정 5건 남짓. `신분증과 산모수첩 또는 임신확인서`처럼 한 줄에 여러 서류가 든 이름은 첫 서류로만 판정됨
- 약한 값 10개 안팎 — `관련사이트 | 고용노동부`, `골목형상점가 | 심리상담센터`
- 검증 문항 14개는 자작. 그중 둘은 기대값이 틀려 판정을 완화함
