## 일간 보고 규칙

- 헤딩: `##### MMDD` (H5, 월 없이 일자 4자리, 공백·구분자 없음)
- 위치: 월간 보고 아래에 월말까지 이어서 누적 작성
- 구조: 3단 — 대분류(대괄호, 맨 왼쪽) > 중분류(4칸, `- `, 끝에 콜론) > 세부(8칸, `- `)

```
##### 0821
[모델 추가]
    - 신규 모델 반영:
        - 엔비디아 네모트론 3.5 라이트닝 모델 추가
        - 서빙 프로바이더 비교 조사 및 사고 모드 비활성화

[지식그래프 데이터 확장]
    - Layer 2 전 분야 확장:
        - 12개 분야 644건으로 확장, 구비서류 관계 890건 적재
        - 법령명 파싱기 구현 및 법령 210종 노드화
    - 검색 품질 개선:
        - 어휘 검색 결합으로 제목 검색 정확도 top1 90% 달성
```

- 대분류 사이는 빈 줄로 띄운다. 대괄호는 대분류에만 쓴다
- 대분류·중분류 제목은 "영역 + 작업 성격"으로 짓는다 (개선·안정화·고도화·정리·대응)
- 세부 항목은 "무엇을 어떻게 했다"를 한 줄로, 서술명사로 끝낸다
  (개선·정리·점검·구현·추가·보강·확장·설계·검토·적용·확인·진행)
- 분량 제한 없음 — 한 일이 많으면 많이 적는다. 적은 날은 대분류 1개로 쓴다
- **대상·작업 성격·성과 수치는 남김** — 월간 보고의 세부 항목이 여기서 나오므로. 대상(서비스·모듈·파일 종류)은 반드시 적고, 한 일이 여러 대상에 걸치면 대상별로 줄을 나눈다
- 빼는 것은 **경위·판단 근거·트러블슈팅 과정·설명 문장** — 왜 그렇게 했는지는 쓰지 않음
- 용도: 그대로 복사해 일일 업무보고에 붙여넣으므로 내부 링크(`[[ ]]`)나 볼트 경로 참조는 쓰지 않음

> 옵시디언 읽기 모드에서는 대분류 아래 4칸 들여쓰기가 리스트로 잡히지 않아 한 문단으로 뭉쳐 보인다. 편집 모드와 복사 결과는 정상이므로 그대로 둔다.

## 월간 업무 보고 생성 프롬프트

> 월말에 아래 프롬프트를 그대로 사용. 규칙이 바뀌면 여기를 고친다

```
이 파일의 일간 보고 내용을 전부 취합해서 아래 양식 그대로 월간 업무 보고를 작성해줘.

2026년 N월 웹사업부 AI 1팀 조경준 월간 업무 보고

1.기본 사항

(1) 이름 : 조경준
(2) 소속 : AI1팀
(3) 직급 : 일반직원
(4) 휴가 : -

2.주요 업무

[대분류]
    - 중분류:
        - 세부 내용
        - 세부 내용
    - 중분류:
        - 세부 내용

[대분류]
    - 중분류:
        - 세부 내용

규칙:
- 3단 구조 — 대분류(대괄호, 맨 왼쪽) > 중분류(4칸 들여쓰기, `- `, 끝에 콜론) > 세부(8칸 들여쓰기, `- `)
- 대괄호는 대분류에만 쓰고, 대분류 사이는 빈 줄로 띄운다
- 대분류 3~5개 / 중분류 2~4개 / 세부 2~4줄
- 대분류·중분류 제목은 "영역 + 작업 성격"으로 짓는다 (개선·안정화·고도화·정리·대응)
- 세부 항목은 "무엇을 어떻게 했다"를 한 줄로, 서술명사로 끝낸다
- 대상을 반드시 밝힌다 — 서비스명·모듈명·파일 종류
- 비슷한 업무는 하나의 대분류로 묶어줘
- 성과 수치는 눈에 띄는 것만 남기고 과정 수치는 쓰지 않는다
- 양식 형태는 절대 바꾸지 마
- 월간 보고는 파일 맨 위, 일간 보고보다 위에 붙여줘
```
