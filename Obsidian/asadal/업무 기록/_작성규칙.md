# 업무 기록 작성 규칙

---

**상세를 먼저 쓰고, 월간은 그것을 압축한다.** 순서를 바꾸지 않는다 — 월간부터 쓰면 상세는 남지 않는다.

| | 위치 | 담는 것 |
|---|---|---|
| 상세 | `업무 일일 기록/<카테고리>/YYYY.MM/MMDD_분류 - 제목.md` | 경위·판단 근거·검증 과정. 그날 이후 고치지 않는다 |
| 계획 | `업무 일일 기록/<카테고리>/계획 및 방향성.md` | 남은 일과 방향. 계속 고친다 |
| 일간 보고 | `월간 업무 보고/YYYY.MM.md` 의 `##### MMDD` | 한 일과 대상. 월말 월간 보고의 재료 |

- 계획은 월 폴더 밖에 둔다. 월을 넘어 이어지는 것이라 안에 있으면 매달 옮겨야 한다
- 세부 형식은 각 폴더의 `_작성규칙.md`를 따른다
