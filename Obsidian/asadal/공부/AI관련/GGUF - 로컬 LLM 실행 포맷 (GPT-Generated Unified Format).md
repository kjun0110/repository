## 개념

LLM(대형 언어 모델)을 **로컬에서 효율적으로 실행하기 위한 모델 파일 포맷**입니다.
`llama.cpp` 프로젝트에서 만들었으며, 기존 GGML 포맷을 대체했습니다.

---

## 핵심 목적

허깅페이스 등에서 받은 수십~수백 GB짜리 모델을 **양자화(Quantization)** 해서 용량을 줄이고,
GPU 없이 CPU만으로도 실행할 수 있게 만드는 것입니다.

---

## 양자화 레벨 (파일명에 표시됨)

| 표기 | 정밀도 | 특징 |
|------|--------|------|
| `Q2_K` | 2-bit | 매우 작음, 품질 낮음 |
| `Q4_K_M` | 4-bit | 용량/품질 **균형 (가장 많이 사용)** |
| `Q5_K_M` | 5-bit | 품질 더 좋음, 용량 증가 |
| `Q8_0` | 8-bit | 원본에 가까운 품질 |
| `F16` | 16-bit | 거의 원본, 용량 큼 |

---

## 사용 방법

`Ollama`, `LM Studio`, `llama.cpp` 등의 툴로 `.gguf` 파일을 바로 로드해서 실행합니다.

```bash
# llama.cpp 예시
./llama-cli -m model.Q4_K_M.gguf -p "안녕하세요"

# Ollama 예시
ollama run llama3
```

---

## 장단점 및 활용

| | 내용 |
|--|------|
| **장점** | GPU 없이 실행 가능, 용량 대폭 절감, 단일 파일로 배포 용이 |
| **단점** | 양자화로 인한 미세한 품질 손실 |
| **주요 사용처** | 로컬 LLM 실행, 엣지 디바이스 배포, 개인 AI 서버 구축 |

---

## 한 눈에 요약

```
GGUF       →  LLM을 내 PC에서 돌리기 위한 압축 포맷
양자화     →  모델 용량 줄이기 (Q4_K_M이 가장 많이 사용)
실행 도구  →  Ollama, LM Studio, llama.cpp
```
