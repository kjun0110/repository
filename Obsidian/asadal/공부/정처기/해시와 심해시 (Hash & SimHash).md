## 개념

- **해시(Hash)**: 임의의 데이터를 고정된 길이의 값으로 변환하는 함수. 입력이 조금이라도 다르면 완전히 다른 값이 나옴
- **심해시(SimHash)**: 비슷한 입력은 비슷한 해시값이 나오도록 설계된 유사도 기반 해시

---

# 해시 (Hash)

```
"안녕하세요"  →  a3f8c2d1...
"안녕하세요!" →  9b71e4a2...  (전혀 다른 값)
```

## 주요 특징

| 특징 | 설명 |
|------|------|
| 단방향성 | 해시값으로 원본 복원 불가 |
| 고정 길이 | 입력 크기와 무관하게 출력 길이 일정 |
| 충돌 최소화 | 다른 입력 → 다른 해시값 (이상적) |
| 결정론적 | 같은 입력 → 항상 같은 해시값 |

## 주요 알고리즘

| 알고리즘 | 출력 길이 | 용도 |
|----------|-----------|------|
| MD5 | 128-bit | 파일 무결성 확인 (보안용 비권장) |
| SHA-256 | 256-bit | 암호화, 블록체인 |
| SHA-512 | 512-bit | 고보안 환경 |
| MurmurHash | 32/64/128-bit | 해시 테이블, 빠른 조회 |

## 활용 사례

- 비밀번호 저장 (DB에 원문 대신 해시값 저장)
- 파일 무결성 검증
- 해시 테이블 (딕셔너리, Map 자료구조)
- 블록체인 트랜잭션 검증

# 심해시 (SimHash)

Google이 웹 페이지 중복 감지를 위해 개발했으며, **유사도 기반 해시(Locality-Sensitive Hashing)** 의 일종입니다.

```
"오늘 날씨가 맑습니다"     →  1101 0011 1010 ...
"오늘 날씨가 맑네요"       →  1101 0011 1001 ...  (비슷한 값)
"파이썬으로 코딩합니다"    →  0010 1100 0101 ...  (전혀 다른 값)
```

## 동작 원리

1. 문서를 토큰(단어)으로 분리
2. 각 토큰을 해시값으로 변환
3. 비트별로 가중치를 합산
4. 최종 합산값의 부호(+/-)로 0 또는 1 결정 → SimHash 생성

## 유사도 측정 — 해밍 거리 (Hamming Distance)

두 심해시 값에서 **다른 비트의 수**로 유사도를 판단합니다.

```
문서A 심해시: 1101 0011
문서B 심해시: 1101 0001
                       ^ 1개 다름 → 해밍 거리 1 → 매우 유사

해밍 거리 ≤ 3 이면 유사 문서로 판별 (일반적 기준)
```

## 활용 사례

- 웹 크롤링 시 중복 페이지 필터링 (Google)
- 표절 검사
- RAG에서 유사 문서 중복 제거
- 뉴스 기사 클러스터링

---

## 해시 vs 심해시 비교

| | 해시 (Hash) | 심해시 (SimHash) |
|--|------------|-----------------|
| 목적 | 동일 여부 판별 | **유사도** 판별 |
| 유사 문서 | 완전히 다른 값 | **비슷한 값** |
| 차이 측정 | 불가 | 해밍 거리로 측정 가능 |
| 활용 | 암호화, 무결성 | 중복 문서 탐지, 표절 검사 |

---

## 한 눈에 요약

```
해시     →  같다 / 다르다  (이진 판별)
심해시   →  얼마나 비슷한가  (유사도 판별)
```
