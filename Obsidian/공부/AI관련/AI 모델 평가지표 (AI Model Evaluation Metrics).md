## 개념

AI 모델이 **얼마나 잘 동작하는지 수치로 측정**하는 지표입니다.
모델의 종류(분류/회귀/생성/검색)에 따라 사용하는 지표가 다릅니다.

---

# F1 Score

정밀도(Precision)와 재현율(Recall)을 **조화평균**한 값으로, 분류 모델의 대표 지표입니다.

## 정밀도 vs 재현율

스팸 메일 분류 예시:
```
전체 메일 10개 중 실제 스팸 5개, 정상 5개
모델이 스팸이라고 예측한 것 4개 (그 중 진짜 스팸 3개)
```

**정밀도 (Precision) — "내가 스팸이라 한 것 중 진짜 스팸 비율"**
```
내가 스팸이라 한 4개 중 진짜 스팸이 3개
→ 정밀도 = 3/4 = 0.75
```

**재현율 (Recall) — "진짜 스팸 중 내가 잡아낸 비율"**
```
진짜 스팸 5개 중 내가 3개 잡음
→ 재현율 = 3/5 = 0.60
```

| 상황 | 문제 |
|------|------|
| 정밀도만 높이면 | 확실한 것만 스팸 처리 → 스팸을 많이 놓침 |
| 재현율만 높이면 | 모든 메일을 스팸 처리 → 정상 메일도 다 걸림 |

## 계산식 (조화평균)

```
F1 = 2 × (정밀도 × 재현율) / (정밀도 + 재현율)

F1 = 2 × (0.75 × 0.60) / (0.75 + 0.60)
   = 2 × 0.45 / 1.35
   = 0.667
```

산술평균이 아닌 조화평균을 쓰는 이유 — 하나라도 낮으면 점수가 확 떨어져서 **둘 다 높아야 좋은 점수**가 나옵니다.
```
정밀도 1.0 + 재현율 0.0 일 때
산술평균 = 0.5  (그럴듯해 보임)
조화평균 = 0.0  (한쪽이 0이면 0 → 더 엄격)
```

## 점수 해석

| F1 Score | 의미 |
|----------|------|
| 1.0 | 완벽한 모델 |
| 0.7 이상 | 양호 |
| 0.5 이하 | 개선 필요 |
| 0.0 | 정밀도 또는 재현율 중 하나가 0 |

# 모델별 지표

## 분류 모델 지표 (Classification)

| 지표 | 한마디 요약 |
|------|------------|
| **Accuracy (정확도)** | 전체 중 맞춘 비율 |
| **Precision (정밀도)** | 맞다고 한 것 중 진짜 맞은 비율 |
| **Recall (재현율)** | 진짜 정답 중 맞춘 비율 |
| **F1 Score** | 정밀도 + 재현율 조화평균 |
| **AUC-ROC** | 임계값을 바꿔가며 성능을 곡선으로 표현, 1에 가까울수록 좋음 |

**Accuracy의 함정:**
```
암 환자 100명 중 실제 환자 1명인데
"전부 정상" 이라고 해도 Accuracy = 99%
→ 이럴 때 F1이나 AUC-ROC가 더 유효
```

## 회귀 모델 지표 (Regression)

수치를 예측할 때 사용 (집값, 온도 등)

| 지표 | 설명 |
|------|------|
| **MAE** | 예측값과 실제값 차이의 평균 |
| **MSE** | 차이를 제곱해서 평균 (큰 오차에 더 민감) |
| **RMSE** | MSE에 루트를 씌운 것 (단위를 원래대로 복원) |

```
실제 집값: 5억
예측 집값: 4.7억
→ 오차: 0.3억  ← MAE는 이걸 평균냄
```

## NLP / 생성 모델 지표

| 지표 | 용도 | 설명 |
|------|------|------|
| **BLEU** | 번역 | 정답 문장과 겹치는 단어 비율 |
| **ROUGE** | 요약 | 정답 요약과 얼마나 겹치는지 |
| **Perplexity** | 언어모델 | 모델이 얼마나 당황하는지 (낮을수록 좋음) |
| **BERTScore** | 생성 전반 | 임베딩 유사도로 의미까지 비교 |

## RAG / 검색 모델 지표

| 지표 | 설명 |
|------|------|
| **Hit Rate** | 정답 문서가 검색 결과에 포함된 비율 |
| **MRR** | 정답이 몇 번째로 나왔는지 평균 |
| **NDCG** | 순위까지 고려한 검색 품질 점수 |

---

## 한 눈에 요약

```
분류 모델  →  Accuracy, F1, AUC-ROC
회귀 모델  →  MAE, MSE, RMSE
생성/NLP   →  BLEU, ROUGE, Perplexity
RAG/검색   →  Hit Rate, MRR, NDCG
```
